# Instagram Audience Analysis Application

## Overview

This application provides Instagram content creators and marketers with tools to analyze their audience demographics, interests, and engagement. It helps users understand their followers better, match relevant products to their audience, generate insightful reports, and derive actionable strategies for content creation and marketing campaigns.

The application uses the Instagram Graph API to fetch audience data securely via OAuth authentication.

## Key Features

*   **Instagram Authentication**: Secure login using Instagram OAuth 2.0.
*   **Audience Demographics**: Visualization of audience data including age distribution, gender breakdown, and top locations (cities/countries).
*   **Interest Analysis**: Fetches and displays audience interests (requires appropriate API permissions).
*   **Product Matching**: Suggests products from a predefined list that align with the user's audience demographics and interests.
*   **Report Generation**: Creates downloadable or viewable reports summarizing audience insights.
*   **Actionable Insights**: Provides data-driven suggestions for content strategy based on audience analysis.

## Technology Stack

*   **Frontend**: React (with TypeScript), Axios, React Router
*   **Backend**: Python (Flask), SQLAlchemy, PyMySQL, Requests, PyJWT
*   **Database**: MySQL
*   **API**: Instagram Graph API
*   **Deployment**: Docker, Docker Compose, Nginx (for serving frontend static files)

## Setup for Local Development (Basic)

**Prerequisites:**
*   Node.js and pnpm (for frontend)
*   Python 3.11+ and pip (for backend)
*   MySQL Server (running locally or accessible)
*   Instagram Developer Account with API Credentials

**Backend:**
1.  Navigate to the `server` directory: `cd server`
2.  Create and activate a virtual environment (if not using the one from the template): `python -m venv venv && source venv/bin/activate` (or `venv\Scripts\activate` on Windows)
3.  Install dependencies: `pip install -r requirements.txt`
4.  Configure your MySQL database.
5.  Create a `.env` file in the `server` directory (see `deployment-guide.md` for structure) and add your database credentials, **NEW** Instagram API keys, and a JWT secret key.
6.  Run the database migrations (handled automatically by `db.create_all()` on first run in `main.py` with this setup).
7.  Start the Flask server: `python src/main.py` (The server will run on `http://localhost:5000`)

**Frontend:**
1.  Navigate to the `client` directory: `cd ../client`
2.  Install dependencies: `pnpm install`
3.  Start the React development server: `pnpm run dev` (The frontend will usually run on `http://localhost:5173` or another port)
4.  The React development server will automatically proxy API requests starting with `/api/` to the backend server running on `http://localhost:5000` (this requires configuring `vite.config.ts` if not already done by the template - check the template's default setup).

**Access:** Open your browser to the frontend development server URL (e.g., `http://localhost:5173`).

## Deployment

For deploying the application to a server (like DigitalOcean), please refer to the detailed instructions in `deployment-guide.md`. This guide covers deployment using Docker and Docker Compose.

## API Credentials & Security

*   **NEVER** commit your API secrets (Instagram App Secret, JWT Secret Key, Database Password) directly into the code.
*   Use the `.env` file in the `server` directory to store these secrets locally.
*   When deploying, configure these secrets using environment variables provided by your hosting platform or Docker Compose.
*   Ensure the `INSTAGRAM_REDIRECT_URI` configured in your `.env` file and deployment environment **exactly** matches the one set in your Instagram Developer App settings.
